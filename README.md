[One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae) ($5).

`main.py` writes the entrant's own make.fun username — one word, nothing
else — to `/output/entry.txt`:

```

```

Run with `python3 main.py`.
